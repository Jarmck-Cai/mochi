# 实验 001：离线验证个性化排序收益

- 状态：设计中（未开始）
- 对应里程碑：M1（写任何 RIME 代码前的前提验证）

## 假设

在术语密集的真实输入分布上，"通用语言模型 + 个人记忆层"的首选命中率比纯通用模型高 ≥10 个百分点。

## 方法（草案，待细化）

1. **数据**：用户本人历史文本（论文、笔记、聊天记录），转为（拼音序列 → 目标文本）对；按时间切分 train/test（防泄漏）
2. **基线**：通用 n-gram 语言模型（开放语料）做词图解码的首选命中率
3. **实验组**：基线 + 个人 n-gram（train 集统计，时间衰减）+ 个人词库插值
4. **指标**：整句首选命中率、术语命中率（重点）、中英混打段命中率
5. **消融**：分别去掉个人 n-gram / 个人词库 / 场景先验，看各自贡献

## 通过标准

- 术语密集场景首选命中率提升 ≥10 个百分点 → 项目前提成立，进入 M2
- 提升 2-3 个百分点 → 回到设计阶段，重新审视价值假设

## 产出

- `report.md`：实验报告（结论写回 STATUS.md 和 ROADMAP）
- 可复用的拼音转换 + 词图解码原型代码（M2 的种子）
