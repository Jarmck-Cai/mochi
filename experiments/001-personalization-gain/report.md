# 实验 001 正式报告：个性化排序收益（M1 门禁）

- 日期：2026-06-10
- 结论：**M1 门禁通过**（整句首选命中率 +13.5pp ≥ 10pp 标准）
- 数据：用户真实语料（隐私：原文与逐句产物在 results/ 与 data/，已 gitignore 永不入库，本报告只含聚合指标）

## 语料

| 部分 | 内容 | 用途 |
|---|---|---|
| 英文论文 ×3（2021，~200KB） | HFO/癫痫源定位领域 | 个人英文术语词库（854→1102 词，含大小写习惯） |
| 中文沟通记录 ×3（2026-03，~22KB） | 微信沟通 + 电话纪要 | 个人中文 LM（train：前 2 篇，285 子句）+ 测试集（最新 1 篇，274 子句，26 条中英混排） |

按文件名时间序切分，测试集严格在训练集"未来"，无泄漏。

## 结果（个人领域测试集，274 子句）

| config | 整句首选命中率 | 字级准确率 | 中英段整句命中 |
|---|---|---|---|
| baseline(generalLM) | 41.6% | 79.0% | 0.0% |
| +personalLexicon | 43.1% | 79.9% | 15.4% |
| +personalLM | 55.1% | 83.8% | 15.4% |
| **full(+LM+lexicon)** | **55.1%（+13.5pp）** | **83.9%（+4.9pp）** | **15.4%** |

- 逐句对比：full 41 赢 / 4 输
- 通用对照集（人民日报 held-out 200 句）：34.5% → 35.0%，**无回退**
- 解码速度 6-11 ms/句（纯 Python 原型，未优化）

## 关键观察

1. **285 条训练子句（约 1100 tokens）就带来 +13.5pp**——"个性化价值主要来自记忆"的假设被真实数据支持，且数据需求量级很小，即时学习闭环（每天几百次输入）完全够喂
2. 消融与替身实验一致：个人 LM 贡献 > 个人词库，叠加最优
3. 术语命中指标本轮无效（术语表被英文论文词主导，与中文电话纪要域不重叠）——后续按场景分桶后应分场景统计（ADR-004）
4. 英文词召回无提升（22.6% 持平）：测试集中的英文多为训练集未见过的新词——印证 DESIGN 中"新术语挖掘"的必要性

## 局限

- 中文语料仅 ~22KB / 3 篇，置信区间宽；电话纪要可能含转录噪声
- 训练/测试同属沟通场景（这恰是目标使用场景，但跨场景泛化未测）
- λ 权重沿用替身语料手设值，未对真实语料调参（提升空间）

## 决定

M1 通过 → 进入 M2（RIME translator + 词图 + 记忆库 + 中英混打）。
