# 失误速记（real-use misfire log）

> 相位 1 的数据入口（见 docs/research/2026-06-12-离线教练分层与快慢协同.md）。
> 真实使用中**首选错了 / 该有的候选没有 / 补全/模糊音误报**就随手记一行。
> 目的：让相位 2（M3 二期语料现代化 = 云教练首秀）对着**真实 miss** 训，而不是凭印象。

## 怎么记（越省事越好）

打字时一旦不顺，记一行即可，格式自由，但尽量带上**拼音串**（最关键）：

```
- `拼音串` 期望「期望词」实际首选「实际词」 [场景/备注]
```

例：
```
- `dazi` 期望「打字」实际首选「大字」 [terminal]
- `suijitidu` 期望「随机梯度」实际首选「随即梯度」 [写笔记，通用 LM 过时]
- `congratulation` 补全没给出 [英文补全漏]
- `pinyin` 模糊音误把别的词顶上来 [模糊音误报]
```

## 原始数据已自动留存（速记只是"标注"，不必写全）

- **brain.log**（`%LOCALAPPDATA%\Mochi\brain.log`）：每次按键的 query + 当时首选 +
  延迟 + 场景，全有。事后能按拼音串回捞上下文。
- **commits.jsonl**（`%LOCALAPPDATA%\Mochi\user_data\commits.jsonl`）：你最终确认上屏的
  每一条；**同输入改选 = 纠正**，是最强的失误信号，relace 脚本能直接挖。

所以这里只需记下"哪条让你别扭"，相位 2 会用拼音串去 brain.log/commits.jsonl 对齐细节。
