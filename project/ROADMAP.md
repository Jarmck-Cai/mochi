# MVP 路线图（按验证顺序，不设时间表）

> 与 README.md 第十节保持一致。每个里程碑有明确的验证标准，通过才进入下一个。

## M1 假设验证 ✅（2026-06-10 通过）

离线模拟"个性化排序 vs 通用排序"的首选命中率差异（experiments/001）。
- 通过标准：术语密集场景提升 ≥10 个百分点
- **结果：真实语料（微信+电话纪要测试集）整句首选命中率 +13.5pp，通用对照无回退**（experiments/001-personalization-gain/report.md）

## M2 基本盘：中英混打

RIME + 自研 translator + 词图解码 + 第 0 层记忆库。单点把痛点 1 做到极致。
- 验证标准：与微软拼音对比，中英混打场景切换次数减少 ≥80%，整句首选命中率不低于微软拼音

## M3 即时学习

纠正即生效闭环 + 文档导入冷启动。
- 验证标准：纠正一次后，相同上下文下次输入首选正确；导入文档当天个人术语可识别

## M4 选择性出手

置信度校准 → 自动上屏。
- 验证标准：在选定覆盖率下错误率 <1%

## M5 魔法时刻：续写预测

UIA 上下文获取 + LLM 续写 + 幽灵文本（阶段 1：候选窗内预览）。
- 验证标准：被接受的续写占显示次数 ≥40%（值得显示率）

## M6 学习闭环自动化

本地重训 + 回归门禁 + （可选）云端教练蒸馏。
- 验证标准：模型周更不回归，top-1 命中率随周数单调上升
