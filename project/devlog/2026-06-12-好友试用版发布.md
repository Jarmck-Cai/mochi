## 本次做了什么

1. **发布套件 release/**：
   - install.ps1：定位 weasel 0.17.4（注册表→默认路径，版本不符直接拒）、
     替换 fork 三件套+rime.dll（原版备份 .stock）、brain+artifacts 装到
     %LOCALAPPDATA%\Mochi、方案部署（已有配置备份 .pre-mochi）、

     好友机器重启自愈，补掉了"重启后 brain 没了"的体验杀手
   - uninstall.ps1：还原 .stock、移除自启、还原 .pre-mochi 配置；
     **个人数据保留不删**（用户的数据由用户处置）

     personal.tsv / commits.jsonl 入包即抛异常）
2. **GitHub Release**：tag v0.2.0-alpha，zip 16MB 上传完成，远端 SHA256
   与本地一致。gh CLI 未装——用 `git credential fill` 取 GCM 里的 token
   走 REST API（创建 release + uploads.github.com 传资产）
3. **macOS 结论（如实）**：无法从现有代码打包——weasel fork / 命名管道 /
   Win32 listener / MSVC 链路全是 Windows 专属。移植 = fork Squirrel +
   IPC 抽象 Unix socket + brain listener 跨平台 + Mac 硬件编译，
   里程碑级工作量，已写入 STATUS 待排期

## 经验沉淀

- **PS 5.1 无 BOM 的 UTF-8 .ps1 当 ANSI 解析**，中文注释直接炸语法——
  发布脚本（会在好友机器上跑的）一律 UTF-8 with BOM
- 下载 zip 解压后的文件带 Mark-of-the-Web，installer 第一步 Unblock-File，
  否则 dll 可能被拒载
- 私有仓库的 Release 资产外人下载不了——分发要么邀请协作者，要么直接
  发 zip 文件（dist\ 本地有留存）
- 给非开发者的安装脚本：版本不符要拒绝而不是警告（fork 二进制绑定
  0.17.4，装错版本是必崩）；好友无法看日志，所以每步都要 Write-Host
