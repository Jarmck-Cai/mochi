# ADR-002: 按"知识的性质"分层，放弃 1.5B + 每周 LoRA 方案

- 状态：Accepted
- 日期：2026-06-10
- 决策者：用户 + Claude

## 背景

v1 方案为"云端大模型每周 LoRA 微调 1.5B 本地记忆模型（目标 15-30ms）"。评审发现三个硬伤。

## 选项

**v1：1.5B 本地 LLM + 每周云端 LoRA**
- 1.5B INT4 在消费级 CPU 上单次前向实际 50-300ms，热路径不可行
- 个人偏好本质是统计记忆（查找表），用梯度下降压进权重是最贵的实现方式；学习延迟一周；有灾难性遗忘风险
- 排序/意图判断是分类问题，不需要生成式 LLM 的泛化能力

**v2：记忆库 + 专用小模型 + 异步 LLM + 蒸馏教练**
- 第 0 层记忆库：即时学习（纠正立刻生效），零训练，用户可编辑
- 第 1 层 ~20M 专用小模型：唯一热路径神经网络，<15ms
- 第 2 层 LLM：异步，不在热路径
- 云端教练：知识蒸馏（产出词库条目 + 训练样本），不做权重微调

## 决策

**采用 v2。** 核心认知：个性化的价值 80% 来自记忆（lookup + 统计），只有 20% 来自泛化；只有泛化才值得用神经网络。

## 后果

- 学习速度从一周变为即时（留存来源）；热路径延迟从不可行变为 ~25ms
- "专属模型"的实现变为"记忆库 + 为你训练的小排序器"，用户体验不变
- 第 2 层 LLM 的续写质量成为新的待验证项（M5）
