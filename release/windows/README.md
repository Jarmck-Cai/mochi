# Mochi（默契）输入法 — 好友试用版（Windows x64）

懂你的个人记忆输入法：中英混打不切换、选一次词立刻记住、越用越懂你。
**所有数据全程本地，不联网、不上传。**

## 安装（约 2 分钟）

1. 安装官方小狼毫 **Weasel 0.17.4**（必须是这个版本）：
   <https://github.com/rime/weasel/releases/tag/v0.17.4>
   下载 `weasel-0.17.4.0-installer.exe`，一路下一步。
2. 解压本 zip 到任意目录，**右键 `install.ps1` → 使用 PowerShell 运行**
   （会请求管理员权限）。
3. `Win+空格` 切换到「小狼毫」。如果当前方案不是 Mochi，按 `F4` 选「Mochi」。

## 试试这些

| 打这个 | 体验 |
|---|---|
| `zheshiyigetest` | 中英混打不用切换：这是一个test |
| `deeplearning` | 英文连写自动分词：deep learning |
| `suijitidu`，选错了再改选一次 | 改一次立刻记住，下次首选就对 |
| `shangxiaw` | 尾部补全：「上下文」，补的"文"是淡色 ghost |
| `pinying` | 模糊音容错：拼音 |
| 长句中段打错 | 候选里有短的"局部候选"，错哪改哪，不用删除重打 |

- 候选不止一页：`-` / `=` 翻页
- 任何时候觉得不对劲：`F4` 切回「朙月拼音」（官方方案，保底能打字）

## 已知边界（试用版如实相告）

- 通用语言模型还在用旧语料训练，部分时髦词组的首选会偏（如 dazi→大字），
  正在重训；**你纠正一次它就记住**，这正是 Mochi 的核心能力
- 英文拼写纠错（seperate→separate）还没上，后续版本加入
- 重启电脑后 brain 会自动拉起（开机自启）；若候选异常，等 2 秒重新打字即可自愈

## 你的数据

- 个人记忆只存在本机：`%LOCALAPPDATA%\Mochi\user_data\commits.jsonl`
  （纯文本，每行一条你确认上屏的记录，可随时打开查看/删行）
- 卸载不会删它；想彻底清除就删掉整个 `%LOCALAPPDATA%\Mochi`

## 卸载 / 还原

右键 `uninstall.ps1` → 使用 PowerShell 运行（管理员）。小狼毫恢复官方原版。
